# docs/

Durable knowledge for this repository, filed by lifetime, mirroring the
convention `coding-agent-rulebook` uses:

- `decisions/` — architecture decisions, fixed at the moment they were made.
- `handbooks/` — living, kept-current reference material.
- `reports/` — point-in-time findings, fixed once written.
- `specs/` — the state machine and other specifications this plugin
  implements. `specs/state-machine.md` is authoritative for this repository.
- `proposals/` — the proposal that authorized this repository's build.
- `_assets/` — images and other binary assets referenced from the above.
